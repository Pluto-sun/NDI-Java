# 项目管理切片 20：区域地图与月末口径

## 业务口径

项目工作台地图保留当前主档视图，并增加已完成月份的月末视图。当前视图反映实时生效主档；选择历史月份后，省市归属、阶段、项目总金额和四类分类金额均读取该月的月末快照。迟到审批通过引起的单项目历史修订会进入该月地图，待审、驳回或撤销申请不改变地图。默认排除已终止项目；选择已终止阶段时必须显式勾选“含已终止项目”。

旧版地图以起止月份查询单一项目所属月份，不能直接等同于新版连续月末快照。因此本版历史地图按单月状态展示，不把数个月的项目数和金额相加。选择月份后只允许读取已生成快照；尚未生成时返回明确错误。历史地市统计不跳转实时项目清单，避免历史数字与当前清单不一致。

## 实现

后端使用统一的区域聚合模型，分别从当前主档及月末快照读取项目数量、总金额、网络化、格物、大数据、万悟金额。主档分类金额先按项目聚合，再按省市汇总，防止一项目勾选多个类别时总金额被重复累加。省市权限在服务层确定，并在响应中将未授权地市的数量与全部金额置零；边界 GeoJSON 仍走独立授权接口。

前端提供月份、阶段、终止口径、六项着色／排行指标、区域勾选及全选／清空。地图支持放大、缩小、四向平移和复位，控制均为带名称的原生按钮；图形不可用时保留区域清单。加载失败提供重试。现有 React 工作台布局与视觉变量保持不变。

## 验证与剩余事项

隔离 MySQL 测试覆盖当前分类金额、历史月末统计、跨月审批修订以及地市权限遮蔽；前端执行格式检查与生产构建，后端执行完整 Maven 验证。浏览器窄屏、键盘以及地图边界服务的端到端操作仍需在后续验收中完成。

项目管理尚未达到全部功能对等。管理配置、生产身份认证和完整浏览器流程仍是后续切片；排产、计收、能力指标保持重新设计范围，不迁移旧实现。
