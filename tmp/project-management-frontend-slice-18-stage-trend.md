# 项目管理切片 18：历史月末阶段趋势

## 口径与实现

旧工作台按“项目唯一归属月份”在起止月份内累计，所选区间的每个项目通常只计一次。新版已采用月末状态快照：同一项目在连续月份均有记录。因此本切片没有把多个月的快照金额相加作为“区间项目总金额”，而是把每个月作为独立时点展示。历史月报的总数与金额仍取结束月份的单月状态。

新增阶段趋势接口在至多 24 个月内，按月末月份、阶段和当前账号的数据范围一次性分组，返回项目数、项目预计总金额与网络化／格物／大数据／万悟四类金额。查询阶段使用固定生命周期代码；默认排除已终止阶段，只有显式勾选“含已终止项目”时才接受该阶段。没有项目的月份与阶段由服务层补零，避免图表断档。前端提供月份、阶段和指标选择；折线图用于观察方向，常显表格保留每个数值，颜色不是唯一信息载体。

## 验证与限制

隔离 MySQL 集成测试覆盖跨月获批后的历史修订、空阶段补零、分类金额、不合法已终止筛选，以及同省两个地市与省分账号的数据范围。`./mvnw -q verify`、`npm run format:check` 和 `npm run build` 均通过；测试环境不写入 3307 应用库。尚未完成真实浏览器的窄屏与键盘操作验收。

这项趋势采用用户定版的月末快照口径，并不等价于旧系统按归属月份累计的区间 KPI。历史区域地图的时间范围与指标切换、正式管理员功能、浏览器端到端验收仍需后续切片完成；当前不宣称项目管理整体功能对等。
