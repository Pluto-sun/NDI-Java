# 项目 Excel 导入与首轮历史迁移演练记录

## 实施范围

本次交付两个相邻切片。Excel 导入采用“上传预检—查看逐行错误—人工确认”流程；确认前不写项目主档。历史迁移独立于在线导入，仅从旧 MySQL 读取 `EFFECTIVE` 项目，并写入一次性隔离 MySQL。旧审批、附件和历史月度快照均未迁移，运行中的 3307 应用库未参与本次演练。

重复项目按“同省、同地市、项目名称经 NFKC 标准化及空白归一化”识别，文件中保留物理顺序第一条，其余行报错且不进入主档；目标库已有同名同地市项目时同样拒绝。导入确认会再次核验属地权限、组织、行业、负责人及目标库重复项。每行单独提交，失败行保留原因，不回滚此前成功行。批次及逐行状态、文件 SHA-256、来源主键映射写入 V10 表。HTTP 入口分别为 `POST /api/v1/projects/imports/preview`、`GET /api/v1/projects/imports/{batchId}`、`POST /api/v1/projects/imports/{batchId}/confirm`。

样例表没有独立的“客户需求”列。Excel 导入暂将“项目建设内容”作为主档 `customer_need` 的历史输入，来源表头及整行预检数据保留在批次审计中；正式模板若拆分两项，应调整字段映射。样例表也没有计收阶段所需的合同编号与签约金额，因此该模板中的计收阶段行会报错，不自动补造。进展列按列名日期写入历史进展，未提供下一步动作的记录保存空文本，不伪造原始内容。

## 样例表预检

`广东项目_系统导入预处理.xlsx` 的“导入数据”工作表有 71 条记录。文件自身没有同省同地市同名重复项；22 行缺项目总金额，不满足已定版的必填规则。已选择三化类别的金额均已填写，未发现类别金额合计超过总金额的行。

在先迁入旧项目的隔离库中调用预检接口，得到 71 行、2 行可确认、69 行失败，未执行该批次确认。错误包含目标库已有项目 45 行、缺项目总金额 22 行、属地目录未匹配 3 行；同一行可能同时命中多个原因，不能将各原因数量直接相加。该结果反映“历史项目已迁入、目录仅由旧库引用数据构成”的特定测试环境，不代表空白正式库的可导入行数。导入前还需准备正式组织和人员目录，并核对省市简称与全称映射。

## 旧库隔离演练与核对

演练脚本为 `scripts/rehearse_legacy_projects.py`。源连接从旧项目 `backend/.env` 的 `DATABASE_URL` 读取，源事务设为只读；目标连接仅通过 `NDI_REHEARSAL_TARGET_URL` 显式提供，数据库名必须以 `ndi_rehearsal_` 开头，且项目主档必须为空、Flyway 至少执行到 V10。隔离库仅复制组织及人员引用，不迁移账号密码。脚本对每个项目单独提交，并输出项目源 ID 到目标 ID 的映射、失败清单及汇总报告。

本次旧库共有 58 个有效项目，原项目总金额合计 33,597.30 万元。48 个项目成功迁入，合计 29,621.30 万元；目标库项目数与金额分别为 48 和 29,621.30 万元，与成功映射一致。10 个项目未进入主档，均缺行业，其中 3 个同时缺客户名称；这 10 个项目也均缺地市客户经理。失败项目金额合计 3,976.00 万元，已在差额中体现，不能计入已迁金额。

成功项目的历史进展 2 条、阶段里程碑 49 条、责任成员快照 143 条均与源库对应项目的记录数一致。历史里程碑中 47 条没有原操作人，目标表因外键要求关联项目创建人；脚本保留源里程碑 ID 和来源类型，报告单独记录该替代关联数量，不把创建人解释为真实操作人。已终止项目在成功迁入的 48 个项目中占 4 个，状态仍为已终止，不恢复、不清空其历史字段。

详细文件位于 `tmp/legacy-rehearsal-20261020/`：`legacy-migration-rehearsal.json`、`legacy-migration-failures.csv`、`legacy-migration-id-map.csv`。失败清单以旧项目 ID、项目编号和稳定原因代码表达，不包含客户名称。演练隔离容器名为 `ndi-rehearsal-20261020`，映射本机 3310；核对结束后已停止但未删除，执行 `docker start ndi-rehearsal-20261020` 可恢复隔离库。应用正式 3307 数据库未连接或写入。

## 验证与后续边界

`./mvnw clean verify` 已通过。新增集成测试覆盖重复项目首条保留、缺金额拒绝、确认前无主档写入、确认后单行写入及来源记录。迁移脚本的再次运行会因目标主档非空而拒绝，防止将演练误当增量同步。上线迁移前仍需对失败的 10 个旧项目补齐客户、行业及地市客户经理；正式组织与省分负责人目录应先验收。导入确认中途进程退出时，批次会停留在 `CONFIRMING`，需要后续补充恢复或人工处置机制，当前不应将该接口用于无人值守的大批量导入。
