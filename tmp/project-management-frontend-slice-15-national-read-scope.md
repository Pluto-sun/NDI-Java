# 项目管理切片 15：全国可读范围

本记录供项目开发与联调留档。排产、计收、能力指标仍按新业务规则重新设计，不以旧系统实现作为本切片范围。

## 缺口与处理

此前 Java 权限模型只有省分、地市两级读取范围，导致集团、数科、数智、广东 DPASS 等全国查看角色无法读取项目工作台与项目清单。地图的全国层级若直接使用省级范围，会遗漏数据或混淆授权边界。因此身份模块新增全国可读范围，项目列表、详情、当前工作台、月末统计与导出任务沿用同一范围判断。

全国查看角色为 `GROUP_REVIEWER`、`DS_TECH`、`DS_INTELLIGENCE`、`GD_DPASS` 和 `SYSTEM_ADMIN`。其中管理员保留跨省读取与数据导出能力，不因此获得项目创建、进展写入或业务审批权限；即使叠加省分填报角色，新建入口也不会显示。省分、地市人员仍受原有组织范围约束。全国范围在持久化导出任务中没有组织编号，Flyway v21 将该列改为可空；任务领取、下载时继续重验申请人的当前范围。

## 验证与边界

集成测试验证五类全国角色的跨省详情、集团与管理员的跨省列表、工作台、全国导出以及业务写入拒绝；月末快照测试验证全国范围读取。`./mvnw -q verify`、补充断言后的 `./mvnw -q -Dit.test=ProjectApprovalIT verify`、前端格式检查与构建均通过。下一步再建立地图专用区域聚合和省市下钻接口，接入页面边界数据。当前工作台仍未提供地图图形，也未完成浏览器交互验收。
