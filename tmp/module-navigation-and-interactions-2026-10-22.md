# 模块导航与交互调整说明

## 菜单与路由

本说明供项目维护和功能验收使用。七个一级菜单为驾驶舱、项目管理、计收管理、排产管理、能力指标管理、消息与审批、个人中心。项目管理驾驶舱沿用原工作台 `/workbench`；其余三个驾驶舱及计收、排产、能力指标业务入口提供独立占位页，不接入旧模块逻辑。

项目管理下设置项目列表、项目导入、项目创建；创建和导入入口仍按原有权限显示，未授予管理员项目创建或审批权限。消息与审批保留未读和待审批数量。个人中心包含个人设置，管理员另外显示账号与组织、接口人范围、督办管理及备份管理。菜单支持折叠，原业务路由保留。

## 资料与省份目录

个人设置支持修改展示用户名（姓名）、邮箱及密码。展示用户名与登录账号区分，修改姓名不改变登录标识。密码修改仍校验原密码，成功后撤销旧会话；未初始化密码的账号须由管理员先配置密码。页面移除开发／生产适用性提示，认证、授权及数据保护规则保持不变。

V37 迁移补齐 34 个标准省级目录，按编码或既有简称／全称识别，保留原组织 UUID、项目归属和已配置范围，不插入业务项目或演示密码。接口人范围列出全部已启用省份，支持全选和清空；范围保存仍遵循版本校验与旧会话失效规则。

## 共用交互组件

账号新增／编辑、密码重置、状态变更、新增省市、项目普通信息编辑、阶段推进、重大变更及备份确认改用共用 Modal。弹窗限制背景交互，支持 Escape 关闭及返回触发按钮；提交中的表单防止误关闭。筛选条件继续留在页面内，不将所有交互强制弹窗化。

共用 Select 保留表单值、必填校验及原有变更事件，用主题化选项面板替代系统选择窗口；支持上下键、首尾定位、Enter、Escape 和点击外部关闭，选项面板在弹窗中保持可操作。按钮、输入框、间距及移动端导航同步紧凑化。实现依据为本次源代码、V37 迁移及项目自动化测试；没有引入新 UI 依赖。

## 验证结果

后端全量集成测试 121 项通过；单元／架构测试 76 项通过，包含新增的自治区和特别行政区简称匹配。项目管理浏览器回归 58 项、正式会话回归 12 项全部通过，覆盖桌面与 375px 小屏，验证省份范围、个人资料、密码修改、角色管理、弹窗焦点、下拉真实选值及既有项目流程。前端构建、格式与 Git 差异检查通过。

本地已加载 V37，全国 34 个标准省级区域加原有演示省份共 35 个可选目录，业务项目未变更。前端地址为 `http://127.0.0.1:5173/`，刷新即可读取新版页面。截图位于 `tmp/module-ui-acceptance/`；样本采用隔离验收数据，不代表当前业务库数量。
