# 项目列表固定筛选区修复

项目列表使用标题栏下方的可用视口高度。筛选、导出工具和分页占用各自所需空间，项目清单使用剩余高度独立滚动，防止记录数量撑长整个页面。

更多筛选条件中的项目编号、项目日期起、项目日期止、编号或名称关键字、所属行业、项目负责人六项横向排列。较窄 PC 窗口支持横向查看。日期规则保留无障碍说明，日期范围错误时显示提示。删除列表顶部的冗余说明。

验证完成 npm ci、npm run build，以及四项隔离环境 PC Playwright 回归。覆盖 1440 和 1120 像素宽度，长表滚动、筛选区域位置、分页可见、高级六字段同排、省市多选与真实 CSV 导出。按 frontend-design 复核截图，截图保存于同目录 project-list-viewport-2026-11-28。
