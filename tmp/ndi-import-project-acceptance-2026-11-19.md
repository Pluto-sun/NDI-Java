# NDI-Java 导入与项目管理改动实施及验证记录

## 实施

| 范围 | 实施内容 |
| --- | --- |
| Excel 导入 | 项目管理、排产、计收、格物部署、万悟部署、已上线智能体、开发中智能体、历史快照及月度 Token 使用统一上限。选定工作表的表头之后最多有 2000 条非空数据行，单个文件最大 20 MiB，页面标注 20 MB。multipart 请求和仓库内 Nginx 模板均为 25 MiB，为附加字段留出空间。模板下拉覆盖第 2 至第 2001 行。 |
| 专用导入和暂存 | 复用现有任务与预检格式，旧模板、暂存及修正数据可继续使用。月度 Token 横表的 2000 行按源数据行计数，单次确认上限按展开后的 2000 条月度记录计。内嵌图片解压后的总量上限为 40 MiB。附件上传仍走现有服务。 |
| 驾驶舱近期变动 | 全部和四个阶段使用同一张固定列宽表，单行显示、超长省略，悬停或聚焦可展开全文。项目名称仍可打开详情，沿用日期和变动数据口径。 |
| 项目列表和筛选 | 项目名称为文本，详情固定在右栏。归属单行展示主省市，类别和签约主体独立，行业放在业务列末尾。行业移入高级筛选，签约主体位于主要筛选。支持多省分、单省分下多地市，以重复 URL 参数记录选值，并兼容旧链接。列表、数量与导出共享筛选，并与服务端数据范围取交集。 |
| 项目负责人和阶段推进 | 新增稳定职责代码 `SOLUTION_SUPPORT`，同项目可配置多人。沿用本人职责、候选账号及项目维护权限校验。方案交流推进招投标时客户侧交流材料选填，拟招标月份严格校验 `YYYY-MM`，审批成功后写入主档。待审旧单使用主档的有效月份，无法取得有效月份时按审批冲突处理。 |
| 详情与其他列表 | 详情固定栏展示项目名和阶段，长名称省略并可查看完整名称。计收导入关闭后返回计收列表，任务仍可恢复。四个能力台账按两行设置数据行高度，并保留右侧操作。 |

Flyway V60 扩展项目人员职责约束，并添加待审申请的拟招标月份字段。现有项目和人员职责沿用原存储格式。

## 验证

在隔离的 MySQL 和 MinIO 环境执行。前端使用 Chromium 1440 × 1000 和 375 × 812 两个视口。生产应用库未执行迁移。

| 核验项 | 核验方式 |
| --- | --- |
| 2000 行与 20 MiB | 项目专用和公共工作簿读取器验证 2000、2001 条边界。浏览器回归提交完整的 20 MiB 工作簿和附加字段，超出 1 字节返回 413。排产向导预检、全选并确认 2000 行，项目预检对 2001 行返回明确提示。 |
| 模板、任务及截图 | 测试模板下拉至第 2001 行，验证项目旧模板和暂存恢复、计收关闭和恢复及接口人创建与导入拦截。月度 Token 专用读取器验证 2000 条源数据行、同一行多月展开、超过 10 MiB 的内嵌图片及 2001 条拒绝。 |
| 人员、阶段和权限 | 验证接口人可为其负责省分的项目配置两名解决方案支撑人员，并拒绝越权绑定。无材料且月份有效可提交，缺月和无效月拒绝，审批后才写入。覆盖有月和无月的旧待审申请。 |
| 列表和驾驶舱 | 在两个视口检查长名称省略、悬停或聚焦、固定详情入口、详情标题栏、筛选与列表返回、四个能力台账行高及固定操作。 |
| 导出 | 验证导出使用已经查询的筛选口径，包括高级筛选、字段选择、项目日期及 CSV 下载。 |

前端构建通过。双视口主回归通过 67 项，2000 行确认用例在桌面运行一次。追加的省市多选导出回归在两个视口共通过 4 项。Maven 全量验证通过 101 项单元测试和 185 项集成测试。将既有迁移与快照测试的断言更新为当前区县目录、能力唯一键及月末生效规则后再执行全量回归。

补充验证旧版项目资料接口更新地市客户经理后，两名解决方案支撑人员及其绑定仍可读取。项目审批集成测试复跑通过 45 项。
