# 项目管理切片 08：导入修正、恢复与剩余功能核对

日期：2026-10-20。本文是开发记录，先保存在 `tmp/`；不构成旧系统全部功能已复现或可上线的验收结论。

## 本次交付

1. 预检时同时保存规范化导入载荷与原始 Excel 单元格。批次创建者可按 Excel 行号修改原模板已有字段，提交时携带修订号；服务端在同一事务内重新校验字段、组织和人员、行业、金额、同批次前序重复项及目标库重名，更新该行与批次有效/失败数量。修订表保存前后单元格、操作者、时间和校验结果。旧批次若没有原始单元格，不能直接修正，应重新上传。
2. 导入确认改为对单行加数据库写锁，已导入行重试时不重复写入。确认中断超过 15 分钟的批次可由创建者手动恢复，调度器每 5 分钟扫描并自动恢复；最终计数从持久化行状态重新汇总，而非使用单次进程内的计数。失败行仍不进入项目主档，其他有效行继续导入。恢复失败会记录日志并留待下一轮重试。
3. 增加与预检表头同源的空白 Excel 模板、填写说明及失败行 Excel 报告；前端提供下载、修正、恢复和状态刷新入口。失败行报告只供批次创建者读取。原有导入计划取消是逻辑取消，不物理清除审计记录。

## 仍未复现的旧功能及下一步

| 范围 | 仍缺的能力 | 下一切片建议 |
| --- | --- | --- |
| 项目导入 | 任意工作表探测、手工表头映射、7 日草稿期限、批次物理删除；原有“导入计划”仅支持严格模板 | 先补工作表探测和安全映射；期限需与留痕策略一起定版，不能直接物理删除审计 |
| 项目主档 | 应用场景、产品支撑专家、拟招标日期、产品推广内容等旧可选字段及部分责任信息修改入口 | 按字段语义补实体、迁移、接口和表单，不存入自由 JSON 规避建模 |
| 项目工作台 | 旧地图及省市下钻、多维筛选尚未完整迁移 | 与当前态/月末态统计共用终止筛选和权限口径，再补地图层级接口与页面 |
| 项目协作 | 长期未更新提醒、转发督办、项目资料删除/保留政策 | 先定提醒接收人与频率、MinIO 对象保留规则，再实现调度和审计 |
| 平台治理 | 正式身份认证、个人资料与密码、账号/角色/区域管理、备份恢复及生产发布验收 | 身份源和登录协议需业务/部署方明确；开发态请求头不得用于生产 |
| 排产、计收、能力指标 | 旧系统的运营台账及各自页面尚未在 Java 项目复现 | 分模块对照旧 `operations` 类型、字段、审批和导入规则，形成可复算样例后分别建模；不混入项目模块 |

这次只关闭了导入链路中的一组缺口。项目管理尚未达到“旧系统全部功能复现”，更不能将四个模块视为已完成。下一步优先推进严格模板之外的导入探测/映射与项目主档字段，再完成地图、提醒、资料生命周期和平台治理；其余三个模块按独立业务模块实施。
