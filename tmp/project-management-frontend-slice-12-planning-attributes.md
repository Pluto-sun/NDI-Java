# 项目管理切片 12：应用场景与拟招标月份

日期：2026-10-20。本记录供项目组核对，确认后可手动移入 `docs/`。

## 实现范围

旧版项目创建表单有七项固定应用场景和精确到月的拟招标日期。此前 Java 项目未保存这两项，导入确认后也会丢失。本切片增加项目主档的拟招标月份列和有序应用场景表；场景代码由领域枚举集中定义，再由基础字典接口提供给前端。创建、普通信息维护、项目详情、草稿恢复、Excel 预检及导入确认使用同一组字段。

拟招标日期在主档统一归一到当月第一天；接口接受 `YYYY-MM`，导入同时接受 `YYYY-MM-DD` 或斜杠分隔形式。应用场景只接受七项固定代码，Excel 另接受对应中文标签。无效日期、未知或重复场景在接口返回稳定业务错误码，在导入预检列出逐行失败原因。普通信息维护保留版本校验和变更事件；旧请求未传新字段时保留已有值，显式传入空月份或空场景列表时清空。已有导入批次缺少新字段时仍按空值确认。
