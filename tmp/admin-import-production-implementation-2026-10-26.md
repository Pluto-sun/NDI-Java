## 2. 排产字段与业务规则

必填：接口人、排产月份、省份、地市、项目名称、客户名称、三化类别。

接口人是文本信息，与系统接口人权限分离。省份、地市从既有行政区划目录选择，校验所属关系。排产月份按 yyyy-MM 保存。项目状态为可空文本，最多 200 字。

| 金额字段 | 类别代码 | 约束 |
| --- | --- | --- |
| 工业专网排产 | NETWORK | 四项至少填写一项；0 是有效值，空值单独保留。 |
| 格物平台排产 | GEWU | 单位万元，不允许负数，最多两位小数。 |
| 工业大数据排产 | BIG_DATA | 填写金额时必须已选择对应类别。 |
| 万悟平台排产 | WANGWU | 允许勾选类别后暂不填写该类别金额。 |

有效记录按“月份＋省份＋地市＋归一化项目名称＋归一化客户名称”唯一。归一化统一全半角、英文大小写并去除空白；接口人不同不能绕过重复校验。不同月份允许重复。删除后保留原记录和操作审计，允许重新创建同一业务键。

权限：管理员全国维护；接口人负责省份内维护；省分角色本省维护；地市角色本市维护；集团、数科、数智、广东 DPASS 全国只读。维护包括新增、导入、修改和删除，首版不审批。

## 3. 导入流程及恢复

项目与排产共用 frontend/src/shared/imports 中的三步界面、字段自动匹配、行修正弹窗、滚动预检及恢复交互，各模块注入自己的 API 与说明。

1. 上传 .xlsx 并选定工作表及表头，限制 10 MB、1000 条数据、最多 128 列；不执行公式，不接受外部链接。
2. 根据表头自动推荐映射，显示必填、选填及条件必填说明。不能跳过步骤；排产至少映射一项金额列。
3. 预检范围、组织、字段、金额和重复记录。用户可修正失败行，再选择通过行确认；一次确认结束任务，其余行放弃，不能续导。

每个模块每个账号独立保留一个未完成任务。任务绑定账号、任务编号和版本；源文件保存在 MinIO 私有目录，服务器读文件时核验大小和 SHA-256。刷新或离开后可以从已到达步骤继续，也可丢弃旧任务重新上传。确认时重新检查数据权限与重复记录。

排产确认将选中行在同一数据库事务内写入；发生并发冲突时整体回滚，保留未完成任务供修正。成功后移除未完成任务，不提供历史任务续导。源文件提交后清理；若存储清理失败会写服务器日志，不影响已提交的业务结果。未完成排产源文件已纳入系统备份对象清单。

## 4. 接口人交接边界

身份模块发布同步事务事件 ReviewerScopeChanged；项目模块订阅事件，在同一事务中锁定项目及申请并交接。身份模块不反向依赖项目模块。范围保存前先检查最终省份归属，再统一释放和分配，支持原子交接，拒绝并发覆盖。

交接对象为待审阶段推进，以及省分发起、由接口人审核的待审重大变更；地市发起、由省分审核的重大变更保持原审批人。已办申请保持历史事实。原接收人的相关通知标记已读，新接收人收到交接通知；管理员不获得业务审批资格。

停用账号时立即撤销登录会话并释放范围，不因待办阻断停用。待审申请保留在管理员“等待接口人交接”清单；为该省配置新接口人后同步转交。配置和交接都会撤销范围变化账号的旧会话。交接会产生本人审批时拒绝并回滚。

## 5. 代码及数据库入口

后端排产模块按 controller、domain、mapper、service、util 组织；有独立配置时加入 config。ProductionRules 统一处理手工维护与导入的业务校验；ProductionAccessService 通过身份目录获取组织权限；ProductionPlanMapper 负责数据库读取及唯一键；ProductionImportService 负责导入流程。

前端入口：/scheduling（排产计划）、/scheduling/new（新增排产）、/scheduling/import（导入弹窗）。列表采用地址参数保留筛选和页码；编辑及删除通过页面内弹窗完成。

API：/api/v1/production/plans 下提供列表、新增、修改、删除、reference-data 和 imports 子接口。所有端点通过身份校验；会话模式写操作保留 CSRF 校验。

- V42：production_plan、production_import_lock、production_import_task。
