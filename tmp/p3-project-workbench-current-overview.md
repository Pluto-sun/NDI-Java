# P3：项目工作台当前经营概览切片实施记录

## 范围与统计口径

本切片为项目管理模块增加当前经营概览，不建设历史月末快照，也不沿用旧系统会改写所属月份的统计事实表。统计只读取当前已生效的项目主档；审批中的名称、金额和阶段申请不进入结果。项目总金额表达商机预计金额，因此接口字段命名为 `totalExpectedAmount`，不把它解释为合同额、计收额或实收额。

默认口径排除当前阶段为 `TERMINATED` 的项目，概览总数、预计金额及阶段分布均采用同一筛选条件。调用方显式传入 `includeTerminated=true` 时，已终止项目纳入总数和金额，并在阶段分布中单列。结果按方案交流、招投标、签约、计收、已终止的固定顺序返回；没有项目的阶段返回零值，默认模式不返回已终止阶段。

## 查询与权限机制

`GET /api/v1/projects/workbench/overview?includeTerminated=false` 返回筛选标志、项目总数、预计金额合计和各阶段的项目数及金额。身份模块计算省分或地市数据范围；省分负责人及接口人读取本省，地市负责人读取本地市，无有效项目读取资格的账号返回 `403`。项目模块通过数据库分组聚合，不将项目明细全部加载至应用内求和。`V8` 迁移补充省分／阶段和地市／阶段组合索引，支撑属地筛选与阶段分组。

## 验证与边界

MySQL 集成测试覆盖待审变更不影响数字、金额变更与终止审批生效后的即时统计、默认排除和显式纳入已终止项目、省市范围隔离、空范围零值、管理员拒绝以及 HTTP 响应。执行 `./mvnw clean verify` 检查迁移、接口和既有业务链路。

本接口表示查询时刻的当前存量，不提供月度趋势、环比、历史某月状态或计收模块金额。未来月末快照需另行确定生成时点、维度、重算范围和终止纳入规则，并从项目里程碑及版本化变更事实构建；本次组合索引不代替未来的快照表设计。大量数据上线前需结合真实数据量检查执行计划，必要时调整索引或建立专用读模型。
