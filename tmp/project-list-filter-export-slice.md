# 项目列表筛选与导出切片实施记录

本记录供 NDI-Java 开发、联调和验收使用。项目列表与导出采用同一组业务筛选条件，服务端始终叠加当前账号的省分或地市读取范围；客户端传入省市编号只会进一步缩小结果，不会扩大授权范围。系统管理员即使兼有填报角色，也不取得项目读取和导出权限。

## 接口与数据口径

`GET /api/v1/projects` 保持原有分页响应，新增 `projectCode`、`projectName`、`stage`、`industryCode`、`provinceId`、`cityId`、`includeTerminated` 参数。项目编号和行业代码精确匹配，项目名称按包含关系匹配并转义 `%`、`_` 等通配字符；多个条件取交集。列表默认包含已终止项目，以维持现有查询行为；传 `includeTerminated=false` 时排除终止项目。排序固定为创建时间、项目 ID 降序，避免同一时间创建的记录跨页顺序不稳定。

`POST /api/v1/projects/exports` 接收同名筛选字段，返回 `202` 和任务编号。提交时对授权结果计数，超过 1000 条则拒绝；后台生成前再次按当时的权限和数据重新查询，若结果超限或权限发生变化，任务记为失败。`GET /api/v1/projects/exports/{exportId}` 查询本人任务状态；`GET /api/v1/projects/exports/{exportId}/download` 仅在任务完成且本人仍拥有原属地读取范围时签发五分钟有效的 MinIO 下载链接，并写入下载审计。

CSV 使用 UTF-8 BOM，固定列为项目编号、项目名称、客户名称、行业代码、项目总金额、当前阶段、网络化金额、格物金额、大数据金额、万悟金额、创建时间。未选的分类金额输出空单元格，不伪装为零；附件、客户需求、合同编号、签约金额及系统运行信息不纳入首版导出。文本单元格执行 CSV 引号转义，并对表格公式前缀作文本化处理。

## 运行与验收边界

任务及筛选条件、请求人、提交时间、处理状态和行数保存在 MySQL；导出文件写入现有 MinIO 存储桶的 `exports/projects/` 前缀。后台每五秒领取一个待处理任务；处理超过十分钟的任务标记失败，由用户重新提交。任务文件当前不自动清理，生产上线前须制定文件保留期和对象清理策略。该任务输出的是后台处理时的当前项目数据，不承担历史月份快照职能。

验收覆盖组合筛选、终止过滤、通配符字面匹配、管理员拒绝、任务生成、跨用户下载拒绝、下载审计、CSV 公式防护，以及真实 MinIO 的文件读回。执行 `./mvnw clean verify` 检查迁移、单元测试、集成测试和模块边界。
