# 项目管理前端

此目录只承载项目管理模块，不预置排产、计收或能力指标的假页面。视觉层沿用旧系统的红色强调与浅色工作台，但代码按 `app/`、`features/`、`shared/` 分层：路由和本地测试身份在 `app/`，项目与工作台页面及其类型化接口在 `features/`，统一 HTTP 封装和展示组件在 `shared/`。页面不得直接拼接后端基地址或读取其他模块的数据库字段。

当前页面包含项目工作台、列表、新建、详情、资料上传、阶段推进、重大变更和指定审批人的待办处理。项目资料采用 SHA-256 校验及 MinIO 预签名直传；阶段材料必须先上传成功，再在申请中选择。审批通过后重新进入项目详情即可读取更新后的主档和里程碑。

开发命令：`npm ci`、`npm run dev`、`npm run build`、`npm run format:check`。Vite 代理指向本机 Java `8080` 端口，资料直传使用后端签发的对象存储地址。生产构建只生成静态资源；生产认证、部署路径与正式菜单需要在上线切片中单独设计，不能使用当前开发账号选择机制。

若 IntelliJ 已占用 `8080`，联调新代码时可另启 Java `8081`，并以 `NDI_DEV_API_TARGET=http://127.0.0.1:8081 npm run dev -- --port 5174` 启动隔离前端。修改代理目标后需重启对应 Vite 进程。
