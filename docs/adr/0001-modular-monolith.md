# ADR-0001：采用模块化单体作为首发架构

**日期：** 2026-10-15
**状态：** 已采纳

## 决策

NDI 以单个 Spring Boot 部署单元和单个 MySQL 事务边界交付首发版本。代码按 `identity`、`organization`、`projects`、`workflow`、`documents`、`production`、`collection`、`capabilities`、`reporting` 划分应用模块，并由 Spring Modulith 架构测试验证依赖关系。

项目管理、排产、计收和能力指标在首发阶段共享组织、权限、审批、附件和项目上下文。采用模块化单体可保持本地事务一致性和单次部署的简单运维，同时以应用接口与领域事件约束未来拆分边界。模块不得跨边界访问持久化实体、Repository 或数据库表。

## 拆分条件

只有某个模块具备独立团队所有权、独立发布节奏、显著不同的资源伸缩特征，或明确的故障隔离要求时，才发起服务拆分评估。评估必须说明接口契约、数据所有权、一致性策略、可观测性、部署方式与回滚路径，并新增 ADR 后实施。
