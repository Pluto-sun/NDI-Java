# P0 业务梳理

P0 用于将旧系统实现、历史数据与业务口径转化为新系统的模块边界和可验收规则。本阶段不创建业务表、不迁移生产数据，也不以旧页面结构替代领域设计。

| 文档 | 用途 | 当前状态 |
| --- | --- | --- |
| [旧系统事实盘点与新系统映射](p0-legacy-inventory.md) | 识别现有能力、历史数据形态、模块映射和需定版事项。 | 首轮完成 |
| [报表与对象存储边界 ADR](../adr/0003-reporting-and-document-storage-boundaries.md) | 固化四模块自有工作台／统计分析、跨模块专题分析与 MinIO 附件存储决策。 | 已采纳 |
| [项目管理领域梳理](projects/README.md) | 细化项目术语、字段、状态、权限与历史数据映射，并集中记录阻断建表的决策。 | P0 工作稿 |

后续按项目管理、排产、计收和能力指标的顺序补充术语、字段、状态、权限、指标和迁移映射。每份领域材料形成书面结论后，才进入对应模块的 Flyway 与接口开发。
