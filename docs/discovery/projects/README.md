# P0 项目管理领域梳理

本目录沉淀 `projects` 模块进入 P2 前的业务事实、候选规则和决策事项。材料服务于内部评审与研发留档；它不构成业务表、Flyway 迁移或接口开发授权。

| 文档 | 用途 | 当前状态 |
| --- | --- | --- |
| [项目管理规则澄清](p0-project-management-rules.md) | 汇总术语、字段、状态、权限、导入与历史映射的已验证事实和建议边界。 | P0 工作稿 |
| [定版决策清单](p0-project-management-open-decisions.md) | 集中记录阻断项目建表的业务决策、决策人和验收证据。 | 待业务评审 |
| [补充答复评估](p0-project-management-response-assessment.md) | 区分本轮补充说明中的已确认规则、代码差异与剩余决策。 | 已完成 |

项目管理工作台／统计分析属于 `projects` 模块；跨模块专题分析由 `reporting` 承载，边界见 [ADR-0003](../../adr/0003-reporting-and-document-storage-boundaries.md)。
