| [定版决策清单](p0-project-management-open-decisions.md) | 集中记录 P2 前的业务决策、范围排除和验收重点。 | 已关闭 |
| [补充答复评估](p0-project-management-response-assessment.md) | 区分本轮补充说明中的已确认规则、代码差异与剩余决策。 | 已完成 |
| [P2 决策场景说明](p0-p2-decision-scenarios.md) | 以项目实例解释 P2 前决策项，并说明旧系统月份统计改写问题。 | 已完成 |
| [项目参考数据字典](p0-project-reference-data.md) | 固化三化类别、41 个工业行业代码及责任字段的引用方式。 | P2 设计基线 |
